# Linux-OpenHack-26

This repository contains the implementation and documentation of the tasks completed during the Linux OpenHack-26.

## Tasks Completed

### Task 1 - Nginx Server Setup
Configured Nginx and hosted the HTML page provided by the organizers.

### Task 2 - Network Access
Accessed the hosted HTML page from another computer on the same network.

### Task 3 - Remote Modification
Modified the hosted HTML page from another computer and verified the changes.

### Task 4 - Multiple Port Hosting
Hosted a different HTML page on port 8080 and verified its accessibility.

### Task 5 - HTTPS
Configured HTTPS for the hosted page using an SSL certificate.
